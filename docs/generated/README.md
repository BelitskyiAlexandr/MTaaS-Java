### Generated Artifact Examples

Example generated artifacts included in this repository are organized by generation category:

```text
docs/generated/
    core/
        Generated relation and function wrappers

    integration/
        Generated integration adapters and registry

    yaml/
        Example generated relation specifications
```

These files are provided only as representative examples of the annotation processor output.

Actual generated artifacts are normally produced inside the Maven `target/` directory during compilation and are excluded from version control.
